## 🌐 Live Application

> **Tomar Kaj is live and available at:**

### 👉 [www.tomarkaj.com](https://www.tomarkaj.com/)

Tomar Kaj is a full-stack **microjob and task marketplace** built around three primary user experiences:

- 👷 **Workers** — discover tasks, complete jobs, submit proof, earn rewards, and manage withdrawals.
- 💼 **Employers** — create campaigns, fund jobs, monitor participation, and review worker submissions.
- 🛡️ **Administrators** — moderate the marketplace, manage users, configure financial rules, and oversee platform operations.

# 💰 Wallet & Financial Flow

### Employer

```text
Deposit Funds
      ↓
Employer Wallet
      ↓
Create / Fund Campaign
      ↓
Campaign Budget / Escrow
      ↓
Worker Completion
      ↓
Employer Approval
      ↓
Worker Reward
```

### Worker

```text
Complete Task
      ↓
Submit Proof
      ↓
Employer Review
      ↓
Approved
      ↓
Reward Added
      ↓
Worker Wallet
      ↓
Withdrawal
```

The platform's financial model includes campaign budgets, platform fees, proof-related fees, withdrawal fees, boosts, and referral commissions.

# 🔐 Security & Reliability

The platform is designed with security and data integrity as core concerns.

### Security layers

```text
Authentication
      ↓
JWT Access Token
      ↓
Refresh Token
      ↓
Role-Based Authorization
      ↓
Protected API Routes
      ↓
Server-Side Validation
      ↓
Transactional Database Operations
```

Additional protections include:

- Password hashing
- Rate limiting
- Security headers
- Controlled administrative access
- Financial transaction safeguards
- Server-side validation

---

# 🧩 Major Engineering Areas

### 🔐 Role-Based Architecture

Separate experiences and permissions are implemented for Workers, Employers, and Administrators.

### 💳 Financial Workflows

The system handles wallet balances, campaign budgets, rewards, deposits, withdrawals, platform fees, and referral commissions.

### 📋 Task Verification

Worker activity is connected to employer verification through a structured proof-submission workflow.

### 🇧🇩 Bangladesh-Focused Payments

Payment workflows are designed around local services such as **bKash** and **Nagad**.

### 🛡️ Marketplace Administration

Administrators have centralized control over users, jobs, campaigns, financial activity, configuration, promotions, and moderation.

### 📱 Responsive Experience

The interface is designed to provide a consistent experience across desktop and mobile screen sizes.
